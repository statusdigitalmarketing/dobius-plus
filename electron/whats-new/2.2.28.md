- Dobius uses less CPU with many tabs open. The once a second check of whether Claude is running in each tab now skips tabs that printed nothing new since the last check.
- Dobius can now measure where its own time goes while it runs, so slowdowns with lots of tabs can be tracked down without restarting anything.
- After a restart, each tab picks up the Claude session it was running, including tabs Dobius could not check for a while before you quit. A session you stopped no longer comes back after a crash.
- Sending a command that starts Claude to a tab where Claude is already running is now refused instead of landing in Claude as a message.
